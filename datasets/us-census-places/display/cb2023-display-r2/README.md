# us-census-places display package cb2023-display-r2

Outline tiles and a names index made from the GeoParquet of `cb2023-r1`, for drawing and choosing places on a map. The GeoParquet is the data; these are not.
The rules and checks are in `display-plan.md` of the dataset workspace.

Source: US Census Bureau, 2023 cartographic boundary files, gazetteer files and population estimates.
