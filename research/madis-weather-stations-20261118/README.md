# A week of MADIS weather station observations

We captured NOAA's public Integrated Mesonet for **November 9–15, 2026 UTC**.
All 168 expected source hours were present. The compressed NetCDF inputs
contained **32,879,643 reports in 5.54 GB**.

The published subset contains **38,932 source-qualified station keys** and
**201,324 latest map readings** across ten measurements. We omitted 185
station keys whose provider's weather redistribution status was restricted
or unresolved. A station key identifies a source and provider record.
Several keys can describe the same physical site.

## What the files support

| Object | Contents | Access |
| --- | --- | --- |
| `data/map.json.gz` | Station coordinates, provider IDs, latest eligible readings in the final source hour, and a station history index | One GET, 3.47 MB |
| `data/history/part-NNN.bin` | Separately gzipped station-week histories, concatenated into 85 packs | One HTTP range GET for the selected station |
| `manifest.json` | The fixed interval, policy hashes, and file sizes and checksums | Fetch once for verification or reuse |

The browser reads the map and finds the selected station locally. It fetches
one compressed history containing all ten supported measurements. Switching
measurements uses the retained history. Desktop browser checks in the
Wasatch, Seattle, Denver and Miami used one map GET and one exact range of
46.3–108.3 KB for a station with measurements. A 390-pixel browser also
loaded Brighton with one map GET and one 87,918-byte range. Changing
measurements made no additional data request. The 88 public files,
including documentation and manifest, total **2.12 GB**. All passed
anonymous SHA-256 readback. [Live demo](https://experiments.folia.sh/weather-stations/)

## Workflow

The [standalone pipeline](pipeline/README.md) runs directly against NOAA. It
includes the 41-column Parquet schema, historical and current-hour
ingestion, the Arrow checks, and the range packager.

1. Fetch NOAA's public Integrated Mesonet files in one fixed half-open window,
   **2026-11-09 00:00 UTC to 2026-11-16 00:00 UTC**. The archive URL pattern is
   `madisPublic1/data/archive/YYYY/MM/DD/LDAD/mesonet/netCDF/YYYYMMDD_HH00.gz`.
   Record each exact URL, source hour, byte count and digest. Check gzip
   integrity, NetCDF structure and hour coverage before converting. [NOAA archive access](https://madis.ncep.noaa.gov/madis_sample_data.shtml)
2. Normalize each source hour to an hourly Parquet file. Keep the original
   observation time, units, provider and station identifiers, QC, missing
   values, and same-time duplicates. The working schema has 41 columns and ten
   measurement rows per report. The original NetCDF files retain the
   full native field set. The source hour identifies a file window.
3. Retain exact provider IDs whose NOAA weather category is 3 and whose
   listed subproviders all have category 3. Exclude unknown, restricted,
   and mixed-category provider groups. Notify NOAA before redistribution and
   preserve provider attribution. The display includes the reliability
   disclaimer. [NOAA restrictions](https://madis.ncep.noaa.gov/madis_restrictions.shtml) · [Provider table](https://madis.ncep.noaa.gov/mesonet_providers.shtml)
4. Build the final-hour map with the newest eligible value for each station
   and measurement within that hour. Select finite values with a known
   observation time and exclude known QC failures. Keep the fuller history
   projection, including missing or flagged records.
5. Compress each station's history separately and concatenate the members
   into packs capped at 24 MiB. Store each member's shard number, byte offset
   and length in the map. Compare the generated byte ranges to the station
   files, check the hosted bytes and CORS, then publish the manifest.

## QA findings

Seattle station `noaa-madis:NOS-NWLON:EBSW1` has 16,940 history rows and
zero numeric values across the ten supported measurements in this week.
Report counts and numeric measurement coverage therefore need separate
denominators. Provider and source identifiers also matter when
linking nearby stations, and a common timestamp alone cannot establish that
two feeds use the same sensor, statistic or averaging period.

The release checks establish byte fidelity and browser access. An independent
readback compared the map values and four selected station histories directly
with the same-hour and same-station canonical NOAA rows, including clocks,
units, known QC failures and repeated rows. A broader assessment of sensor
accuracy and historical continuity remains open. This is a fixed historical
slice. The map's latest layer is relative to the release window.

## Verify a public history read

The standard-library reader verifies the manifest checksum, the map checksum,
the shard byte range and the decoded station key. A passing check requires
HTTP 206 with the exact range and length declared by the map. It fetches one
station's data in addition to the manifest and map.

```sh
python3 research/madis-weather-stations-20261118/verify_release.py
```

Pass a different published station key to check that station. The script
prints counts, timestamps and decode details without writing files.

reliability of the observations.
